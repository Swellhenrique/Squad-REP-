# Projeto de QA – REP+ | Guarani Sistemas

## Objetivo
Realizar atividades de Quality Assurance (QA) no sistema REP+, da Guarani Sistemas, com foco na análise de funcionalidades, elaboração de critérios de aceitação e execução de testes manuais.

## Atividades desenvolvidas

- Análise de funcionalidades do sistema.
- Elaboração de critérios de aceitação.
- Criação e documentação de casos de teste.
- Execução de testes manuais.
- Testes exploratórios.
- Identificação e documentação de possíveis bugs.
- Coleta de evidências por meio de prints e vídeos.

## Funcionalidades testadas

### Alteração de senha
- Validação de alteração com sucesso.
- Tentativa de autenticação com senha antiga.
- Autenticação com nova senha.
- Validação de senha atual incorreta.
- Validação de confirmação divergente.
- Validação de campos obrigatórios.

## Evidências
